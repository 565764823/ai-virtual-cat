# 🐱 AI 虚拟猫咪陪伴养成应用

一款会「记得你、懂你情绪、陪你成长」的 AI 虚拟猫咪伴侣 App。
核心不是「养一只会动的宠物」，而是「一个长期记住你、回应你情绪、陪你记录生活的数字生命」。

## 核心功能

- 🐈 **选猫养成**：领养专属猫咪，成长等级 / 亲密度 / 三态养成
- 💬 **双向聊天记忆**：拟人化对话 + 长期记忆，越养越懂你
- 💗 **情绪陪伴**：情绪识别 + 多策略回应 + 陪伴模式
- ⏰ **生活提醒**：作息 / 用药 / 学习打卡等拟人化提醒
- 📚 **学习 / 健康 / 心情记录**：三大记录 + 统计可视化
- 🎉 **纪念日倒数**：重要日子的倒数 / 正数与仪式感
- 📅 **月度回忆**：每月情感沉淀报告
- 🎮 **动态互动**：可视化猫咪形象 + 互动玩法

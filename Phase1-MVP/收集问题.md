## 二、本阶段常见问题分类（预判）

### A. 依赖与包引入
- Unity 拉 git URL 包（VContainer/UniTask/XCharts）失败（网络/代理/版本 tag 不存在）
- NuGetForUnity 装 sqlite-net-pcl 后 SQLitePCLRaw 原生库加载失败（`Batteries_V2.Init()` 异常）
- asmdef 程序集引用名与实际包程序集名不符，编译报「找不到类型/程序集」
- 命令行下 nupkg 时 NuGet flatcontainer 包名**大小写敏感**（须全小写，如 `sqlitepclraw.core`）；native `e_sqlite3.dll` 放 `Assets/Plugins/x86_64/` 走架构子目录约定

### B. 数据层（sqlite-net-pcl）
- 误用 `CreateTable<T>()` 生成 PascalCase 列名，与 schema.sql 不一致
- `DateTime` 被存成 ticks，破坏 TEXT 时间戳约定
- LINQ 表达式映射 snake_case 列名失败（漏 `[Column]`，报 `no such column`）
- `PRAGMA foreign_keys` 未在新连接开启，级联删除失效

### C. DI / UI
- VContainer 注入动态 AddComponent 的 MonoBehaviour 依赖为 null（未 `_resolver.Inject`）
- VContainer 对多构造函数的类型默认选「参数最多」者，需用工厂显式 new（如 SqliteDatabase 双构造 → 见 Q1-006）
- Screen 切换时旧 UI 未销毁 / 事件泄漏
- 程序化 uGUI 布局（LayoutGroup/锚点）在中文/多行文本下错位

### D. 功能
- 本地 LLM 流式输出打字机效果卡顿
- 桌面通知（Windows Toast）权限/兼容问题
- 敏感词过滤误杀正常对话
- 人设 System Prompt 须按领养猫动态渲染（品种/性格/口癖），勿固定加载默认实例导致人设错位（见 Q1-010）

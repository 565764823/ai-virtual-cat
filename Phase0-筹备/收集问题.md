## 二、本阶段常见问题分类（预判）

### A. 环境与依赖
- Unity LTS 版本与 LLMUnity 包兼容性问题
- GGUF 模型路径含中文/空格导致加载失败（模型建议放纯英文路径）
- Python 环境与 llama.cpp / ONNX Runtime 依赖冲突

### B. 核心功能（LLM / 情绪 / 记忆）
- 人设 Prompt 输出「不像猫」，语气/口癖不稳定
- 本地 LLM 推理速度慢、显存/内存占用过高
- 情绪分类误判（混淆「焦虑」与「压力」等相近情绪）
- 记忆抽取质量差（抽取无关信息 / 漏抽关键事实）
- Embedding 向量检索召回不相关记忆

### C. Unity 集成
- LLMUnity 在 Unity 内加载模型崩溃 / 卡死
- 流式输出在 UI 上打字机效果不流畅
- SQLite 在 Unity 内的 C# 驱动（如 sqlite-net / Microsoft.Data.Sqlite）兼容问题

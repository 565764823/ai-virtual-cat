## 二、Unity 安装（统一放 D 盘）

### 2.1 Unity Hub

- 官方 exe 安装包（约 132MB）：`https://public-cdn.cloud.unity3d.com/hub/prod/UnityHubSetup.exe`
- 静默安装到 D 盘：
  ```powershell
  & "D:\Unity\UnityHubSetup.exe" /S /D=D:\UnityHub
  ```
- 安装后路径：`D:\UnityHub\Unity Hub.exe`

> ⚠️ 经验：`winget install Unity.UnityHub` 装的是 Microsoft Store（MSIX）版，**不支持命令行 headless 安装编辑器**，且程序文件在受保护的 `WindowsApps` 目录。自动化场景务必用官网 exe 版。

### 2.2 Unity 编辑器（Unity 6 LTS）

- 选型：Unity 6 LTS `6000.0.81f1`（changeset `6238fec1e98f`），来源 `https://services.api.unity.com/unity/editor/release/v1/releases?stream=LTS&version=6000.0`
- 独立安装包（不依赖 Hub CLI，NSIS 静默安装）：
  ```
  https://download.unity3d.com/download_unity/6238fec1e98f/Windows64EditorInstaller/UnitySetup64-6000.0.81f1.exe
  ```

> ⚠️ **下载踩坑（2026-08 实测）**：`download.unity3d.com` 由 Akamai 按出口 IP 做 GeoIP 强制重定向——**大陆/港澳台/部分日本数据中心 IP 都会被 302 到 `download.unitychina.cn`（阿里云 OSS）**，而该 OSS 上 Unity 6 系列文件缺失（`404 NoSuchKey`，2025 年 7 月以来的官方已知问题），导致国内直连、香港/日本节点、NoUnityCN 公益代理全都下载失败。
>
> ✅ **唯一可行解：代理挂「美国节点」**（实测 `142.249.36.78` 洛杉矶可下）。下载命令：
> ```bash
> curl -sSL -C - --retry 5 --retry-all-errors \
>   --proxy http://127.0.0.1:7890 \
>   -o /d/Unity/UnitySetup64-6000.0.81f1.exe \
>   "https://download.unity3d.com/download_unity/6238fec1e98f/Windows64EditorInstaller/UnitySetup64-6000.0.81f1.exe"
> ```
> 校验：`Content-Length: 3954499472`（约 3.95GB）。

- 静默安装到 D 盘：
  ```powershell
  & "D:\Unity\UnitySetup64-6000.0.81f1.exe" /S /D=D:\Unity\Editors\6000.0.81f1
  ```

> ⚠️ Unity Hub 3.20 的老 `-- --headless install` 语法已失效（Electron 版改用新的 `unity` CLI，仍为 beta），故本机改用独立安装包静默安装，绕开 Hub CLI。

## 三、许可证激活（Personal · 国际版）

> ⚠️ **最大坑（2026-08 实测）**：国内默认下到的 `UnityHubSetup.exe` 是**团结版 Hub（Tuanjie Hub，中国特供，版本 3.3.5）**，它强制登录走 `api.unity.cn`（中国认证），无论怎么改系统地区/语言都跳 `.cn`，无法激活国际版 Unity 6。**必须换国际版 Unity Hub（3.20+）**。
>
> 另外 **Personal 免费版不支持手动离线激活**（`.alf → .ulf` 只适用 Pro/企业版），只能在线登录激活。

**正确激活流程**：

1. 挂**美国节点**代理（出口 IP 必须美国，香港/日本/台湾节点均不行）。
2. 浏览器（Chrome）打开 `https://unity.com/download` → 用**国际账号**登录（走 `api.unity.com`，不是 `.cn`）→ 下载**国际版 Unity Hub**（版本 3.14+，非 3.3.5）。
3. 卸载团结版 Hub：`"D:\UnityHub\Uninstall Unity Hub.exe" /S`，并删缓存 `%AppData%\UnityHub`。
4. 安装国际版 Hub → 登录 → Settings → Licenses → Add → **"Get a free personal license"**。

> **地区判断是综合的**（出口 IP + `Accept-Language` + 时区 + GeoID），登录后 Region ID 写入 `%APPDATA%\Unity\Editor\EditorUserSettings.asset`。若仍跳 `.cn`，依次清：① 出口 IP 换美国 ② `Set-WinHomeLocation -GeoId 244`（改美区）③ `tzutil /s "Pacific Standard Time"`（改美时区）。

> **验证成功**：`C:\ProgramData\Unity\Unity_lic.ulf` 生成，且编辑器日志出现 `Product: Unity Personal`。

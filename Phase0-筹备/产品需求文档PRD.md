## 一、产品概述

### 1.1 一句话定位

**「你的专属 AI 猫咪，不止陪伴，更懂你。」**

一款会「记得你、懂你情绪、陪你成长」的 AI 虚拟猫咪伴侣 Steam 游戏。核心不是「养一只会动的宠物」，而是「一个长期记住你、回应你情绪、陪你记录生活的数字生命」。

### 1.2 价值主张（差异化）

1. **有记忆，才叫陪伴**：猫咪跨会话记住用户关键信息，越养越懂用户
2. **情感引擎，而非问答机器人**：围绕「情绪识别 → 回应策略 → 陪伴模式」设计
3. **陪伴 + 记录闭环**：「聊天、提醒、记录、回忆」串成完整情感陪伴链路
4. **隐私可控**：所有记忆用户可见、可改、可删，数据不出本机

### 1.3 目标用户画像

| 画像 | 特征 | 核心诉求 |
|------|------|---------|
| 孤独青年 | 独居/独处时间多，缺倾诉对象 | 随时在线的陪伴与倾听 |
| 情绪波动人群 | 焦虑/压力大，想疏导 | 倾诉 + 情绪记录 + 被回应 |
| 自我成长型 | 想养成学习/健康/心情记录习惯 | 提醒 + 打卡 + 鼓励的正向循环 |
| 云吸猫用户 | 爱猫但条件受限 | 治愈感 + 拟人互动 |

### 1.4 典型场景（验收用例锚点）

| 场景 | 用户行为 | 猫咪回应 | 关联模块 |
|------|---------|---------|---------|
| 深夜失眠 | 说「我睡不着」 | 进入睡前陪伴，安抚引导放松 | 聊天+情绪 |
| 备考焦虑 | 说「考试好紧张」 | 安抚 + 拆任务 + 设复习提醒 | 情绪+提醒 |
| 失恋难过 | 倾诉心事 | 共情安慰 + 记录情绪 | 情绪+心情记录 |
| 坚持打卡 | 记录学习/运动 | 鼓励表扬 + 连续打卡成就 | 记录+成就 |
| 纪念日 | 临近生日/纪念日 | 主动提醒 + 祝福 | 纪念日 |
| 日常云吸猫 | 抚摸、逗猫 | 卖萌互动 + 亲密度提升 | 动态互动 |

## 二、功能需求

> 每条功能包含：**功能描述 / 用户故事 / 功能细节 / 验收标准 / 优先级**。验收标准可映射到 [`合并代码.md`](合并代码.md) 的测试用例。

### 2.1 选猫养成 🐈

**功能描述**：用户首次进入时，从多只不同品种、性格、外观的猫咪中选择并领养。

**用户故事**：作为新用户，我希望选一只符合我审美的猫并给它命名，以获得专属陪伴感。

**功能细节**：
- 品种与性格：英短、布偶、橘猫、三花、暹罗等；性格标签（黏人/高冷/话痨/懒散/活泼）
- 个性化外观：毛色、花纹、眼睛颜色、配饰（铃铛/围巾/帽子）
- 养成系统：成长等级（幼猫→成猫→资深伙伴）、亲密度、三态（心情/精力/健康）
- 多猫共存（远期）：记忆按「用户级（共享）+ 猫级（专属）」双层归属

**验收标准**：
- [ ] 首次进入展示 ≥3 只可选猫，含品种/性格/外观信息
- [ ] 用户可完成「选猫 → 命名 → 领养」流程，领养结果持久化
- [ ] 再次启动直接进入已领养猫咪（游客存档）

**优先级**：选猫/命名 = MVP；三态养成 = MVP（简化版）；外观自定义/多猫 = P2+

---

### 2.2 双向聊天记忆 💬

**功能描述**：核心差异点。基于本地 LLM 的拟人化猫咪口吻聊天，具备短期上下文 + 长期记忆。

**用户故事**：作为用户，我希望猫咪能像真的猫一样聊天，并且下次还记得我告诉它的事。

**功能细节**：
- 自然对话：拟人化猫咪口吻，可自定义说话风格
- 短期记忆：当前对话上下文（MVP）
- 长期记忆：关键信息结构化存储，跨会话调用（P2+）
- 记忆摘要：压缩长对话控制上下文长度（P2+）
- 主动回忆：主动提起「你上次说下周考试」（P2+）
- 记忆管理：查看/修改/删除记忆（P2+）

**验收标准**：
- [ ] 输入文字后本地 LLM 流式返回猫咪口吻回复
- [ ] 单轮对话内上下文连贯（短期记忆生效）
- [ ] （P2+）跨会话能调用已存储的长期记忆

**优先级**：文字聊天 + 短期记忆 + 流式输出 = MVP；长期记忆/主动回忆/管理 = P2+

---

### 2.3 情绪陪伴 💗

**功能描述**：识别**用户（人类）**当下情绪并给予恰到好处的回应。

> **概念区分（重要）**：本模块的「情绪识别」针对的是**用户**——从用户输入的文字中分析出「开心/难过/焦虑/压力/疲惫 + 强度 1~5 + 置信度」，用于决定猫咪如何回应。它与猫咪自身的「三态」（心情/精力/健康）是**两套独立数据**：后者是养成机制驱动的数值（投喂/玩耍/休息增减），不是文本情绪分类。开发时勿将两者混为同一套数据。

**用户故事**：作为用户，我希望猫咪能察觉我难过/焦虑，并安慰我。

**功能细节**：
- 情绪识别：对**用户输入文本**做情绪分析（开心/难过/焦虑/压力/疲惫等，强度 1~5）+ 置信度
- 回应策略：难过→安慰+引导倾诉；焦虑→安抚+实用建议；开心→共情庆祝
- 陪伴模式：睡前/压力/专注陪伴
- 情绪日记：自动生成情绪曲线（P2+）

**验收标准**：
- [ ] 情绪识别返回细粒度标签 + 强度 + 置信度，达可用准确率
- [ ] 不同情绪触发不同回应策略（可人工验证区分）

**优先级**：基础情绪识别 + 回应策略 = P2（MVP 仅聊天）；情绪日记可视化 = P2+

---

### 2.4 生活提醒 ⏰

**功能描述**：猫咪化身贴心管家，在恰当时间提醒用户。

**用户故事**：作为用户，我希望设置喝水/吃药/学习提醒，且提醒像猫咪说的。

**功能细节**：
- 提醒类型：作息/用药就医/学习打卡/自定义（一次性 + 循环）
- 拟人化提醒：由猫咪「说」出来（游戏内），非冷冰冰系统通知
- 提醒关联：与学习/健康记录联动，可一键打卡
- 智能提醒（远期）：按作息自适应推荐时间，需透明告知 + 可关闭

**验收标准**：
- [ ] 可创建一次性/循环提醒，到期触发桌面 + 游戏内通知
- [ ] 提醒文案为猫咪拟人化口吻
- [ ] 提醒后可一键打卡

**优先级**：自定义提醒 + 桌面通知 + 打卡 = MVP；智能推荐 = P5+

---

### 2.5 学习 / 健康 / 心情记录 📚

**功能描述**：三大记录模块，构成自我成长数据底座。

**功能细节**：
- 学习记录：时长、科目、目标打卡、专注计时（番茄钟）
- 健康记录：饮水、睡眠、运动、体重、生理期、用药
- 心情记录：每日心情打卡（情绪 + 强度 + 一句话原因）
- 统计可视化：周/月趋势图、习惯养成曲线、连续打卡成就
- 猫咪反馈：记录后鼓励/点评，形成「记录→被回应」闭环

**验收标准**：
- [ ] 可完成心情打卡并持久化，展示简单曲线（MVP）
- [ ] （P2+）学习/健康记录 + 统计可视化

**优先级**：心情记录 + 简单曲线 = MVP；学习/健康/统计 = P2+

---

### 2.6 纪念日倒数 🎉

**功能描述**：重要日子猫咪陪你一起数。

**功能细节**：纪念日管理（CRUD）、倒数/正数模式、首页卡片、临近提醒（3/1/当天）、当天祝福、关联回忆。

**验收标准**：
- [ ] 可增删改查纪念日，正确计算倒数/正数天数
- [ ] 临近（3/1/当天）触发提醒 + 当天祝福

**优先级**：P4（Phase 4）

---

### 2.7 月度回忆 📅

**功能描述**：把时间沉淀成可回味的记忆。

**功能细节**：每月整理聊天金句/心情变化/打卡成就/重要事件；图文卡片、时间线、精选片段回顾。

**验收标准**：
- [ ] 每月自动生成回忆报告（金句/心情变化/成就/时间线）

**优先级**：P4（Phase 4）

---

### 2.8 动态互动 🎮

**功能描述**：让猫咪「活」起来。

**功能细节**：Live2D 可视化猫咪、抚摸/投喂/逗猫棒/换装、状态驱动动画、随机互动、轻量小游戏（规划）。

**验收标准**：
- [ ] （P2+）猫咪形象随状态/对话做表情动作

**优先级**：可视化猫咪 + 状态动画 = P2+；互动玩法 = P3；小游戏 = 远期

## 三、非功能需求（NFR）

| 类别 | 指标 | 验收标准 |
|------|------|---------|
| 性能 | 流式首字响应 | < 1~2s（本地推理，完整回复视硬件） |
| 性能 | 游戏启动 | < 2s（首启不强制下载大模型） |
| 可用性 | 离线可用 | 单机离线、无网络依赖 |
| 隐私 | 数据本地化 | 全程不出本机；记忆可查/改/删 |
| 安全 | 内容安全 | 本地敏感词过滤 + 危机识别引导 |
| 合规 | 平台审核 | 过 Steam 内容审核；未成年保护 |
| 可扩展 | 模块化 | 支撑多宠物/多模态/内容更新 |
| 可靠性 | 存档 | 定期备份 + 损坏自恢复 + 迁移脚本 |

## 五、UI/UX 需求

- 界面基调：治愈、温暖、拟人；猫咪形象是视觉核心
- 对话：打字机式流式输出，猫咪有「正在思考/甩尾巴」等状态反馈
- 通知：猫咪拟人化口吻，而非系统生硬提示
- 记录：轻量打卡，记录后必有猫咪回应（正向循环）

## 七、评审结论（已确认）

> 评审于 2026-08-17 通过，以下开放问题逐条确认，作为后续任务输入：

1. **猫咪口吻基线** → 固定一套人设（名字/口癖/自称），作为 T0-3 评测基线。
2. **情绪粒度** → MVP 用 5 类（开心/难过/焦虑/压力/疲惫），强度 1~5；识别对象为**用户**。
3. **记忆归属标记落地时间** → MVP 阶段即建好「用户级/猫级」字段，避免 P2 返工。
4. **游客存档 vs Steam 登录** → MVP 默认游客存档，Steam 登录可选。
5. **提醒触达范围** → MVP 做桌面系统通知 + 游戏内通知。
6. **首个轻量模型** → Qwen2.5-1.5B 起步（体积/速度由 T0-2 实测后定夺）。
7. **危机识别时机** → MVP 仅敏感词过滤；自伤/危机引导留到 P2。

# 🧠 记忆抽取与注入评测集（T0-5）

> 3 段对话（抽取 ground truth）+ 5 条查询（检索 ground truth）。
> 只验证「最小闭环是否跑通」：抽取能否抽出值得记的事实、检索能否把相关事实捞回来、注入后猫咪能否「记得」。

## 通过标准

| 指标 | 门槛 | 说明 |
|------|------|------|
| 抽取召回 | ≥ 80% | 期望关键词出现在抽出的「事实/客体」里 |
| 检索命中（top-3） | ≥ 60% | 查询的 top-3 记忆里含期望关键词 |

> 说明：POC 阶段向量用**字符 n-gram 哈希基线**（零依赖、离线、确定性），语义向量（`--embeddings` / bge-small-zh）留到 Phase 2 落地。因此检索门槛按基线能力设定，不苛求语义精度。

## 一、抽取 ground truth

| 对话 | 内容要点 | 期望抽到的事实（关键词） |
|------|---------|------------------------|
| C1 | 铲屎官开始准备考研 + 喝咖啡提神 | 考研、咖啡 |
| C2 | 铲屎官讨厌香菜 + 给猫起名「奶盖」因为是橘色 | 香菜、奶盖、橘猫 |
| C3 | 铲屎官下周有面试 + 面试程序员岗位 | 面试、程序员 |

## 二、检索 ground truth

| 查询 | 期望命中的记忆 |
|------|---------------|
| 我最近晚上都在复习，好累 | 考研 |
| 今天外卖想点香菜味的，怎么样 | 香菜 |
| 奶盖你是什么颜色的猫呀 | 橘猫 |
| 面试好紧张怎么办 | 面试 |
| 给我冲杯咖啡吧 | 咖啡 |

## 三、判定细则

- **抽取召回**：期望关键词（子串）出现在该对话抽出的任意「事实」或「客体」字段里即算命中。
- **检索命中**：查询的 top-3 记忆（按余弦相似度）里，任意「事实」或「客体」含期望关键词即命中。
- **翻车**：抽取输出非法 JSON、归属字段不在 {用户, 猫}（脚本会归一化兜底）。
